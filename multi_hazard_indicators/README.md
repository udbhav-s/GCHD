# Multi-Hazard Indicators

Two composite indicators summarise children's exposure to multiple simultaneous hazards across the GCHD hazard catalogue.

| Indicator | Folder | Description |
|---|---|---|
| **Multi-Hazard Count (MHC)** | [`mhc/`](mhc/) | Number of distinct hazard categories a location is exposed to |
| **Multi-Hazard Intensity (MHI)** | [`mhi/`](mhi/) | Continuous 0–10 composite hazard intensity score from PCA |

Together, MHC and MHI enable identification of:
- **Hotspots** where children face several hazards simultaneously (high MHC)
- **High-severity areas** where the combined intensity of hazards is extreme (high MHI)
- **Areas needing differentiated response** — e.g., frequent mild events vs. infrequent catastrophic events
