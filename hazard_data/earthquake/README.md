# Earthquake

> **Status: Planned — Q3 2026**

This layer is under development. Documentation and processing scripts will be added when the earthquake hazard layer is integrated into GCHD.

## Planned Data Source

Global seismic hazard data from the **Global Earthquake Model (GEM) Foundation** (https://www.globalquakemodel.org/), providing probabilistic ground shaking estimates at standard return periods.

## Planned Metric

Peak Ground Acceleration (PGA) at 475-year return period (10% probability of exceedance in 50 years).
