# Conflict

> **Status: Planned — Q3 2026**

This layer is under development. Documentation and processing scripts will be added when the conflict hazard layer is integrated into GCHD.

## Planned Data Source

Armed conflict event data from the **Armed Conflict Location & Event Data Project (ACLED)** (https://acleddata.com/) or the **Uppsala Conflict Data Program (UCDP)** (https://ucdp.uu.se/), aggregated to subnational administrative units.
