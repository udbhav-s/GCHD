# Landslide

> **Status: Planned — Q3 2026**

This layer is under development. Documentation and processing scripts will be added when the landslide hazard layer is integrated into GCHD.

## Planned Data Source

Global landslide susceptibility data from **NASA's Global Landslide Hazard Assessment** (https://gpm.nasa.gov/landslides/) or the **UNDRR Global Assessment of Risk** landslide model.
