# Volcano

> **Status: Planned — Q3 2025**

This layer is under development. Documentation and processing scripts will be added when the volcano hazard layer is integrated into GCHD.

## Planned Data Source

Global volcanic hazard data from the **Global Volcano Model (GVM)** and **Smithsonian Institution Global Volcanism Program** (https://volcano.si.edu/), providing proximity-based or probabilistic volcanic hazard zones.
